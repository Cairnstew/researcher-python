## What this is

Unified Python wrapper + CLI to search/fetch scholarly papers across 5 sources (`arxiv`, `openalex`, `semantic_scholar`, `crossref`, `pubmed`) behind one `Paper` model and one pipeline.

## Decisions (final — do not relitigate)

- **D1** Write Crossref + Semantic Scholar adapters now; defer live verification to `scripts/verify_live.py` (user runs it later from a non-rate-limited IP). Mark those adapters `unverified-live` below.
- **D2** Declare `httpx` explicitly in all 3 places (`pyproject.toml`, `nix/default.nix`, `flake.nix`) — don't rely on habanero's transitive dep.
- **D3** DOIs are case-insensitive: `normalize_doi` may lowercase for _keys/dedupe_, but send the DOI to APIs as given by the user (stripped of URL prefix). Do not "fix" mixed-case DOIs.
- **D4** Parse functions are pure (dict/XML in → `Paper` out) so tests use fixtures, never the network.
- **D5** Missing/unavailable adapter must raise `SourceUnavailableError`, not `ModuleNotFoundError` (fix in `get_source_class`).
- **D6** PubMed XPaths must be strictly scoped `./MedlineCitation/…` (never unscoped `.//`).
- **D7** Semantic Scholar: keyless endpoints 429 persistently → key handling is load-bearing; raise `ConfigurationError`/clear message when key needed.
- **D8** HTTP 5xx from a source -> `SourceError`. `SourceUnavailableError` only for missing/unconstructable adapters (D5). No retry loops inside adapters; retry/backoff, if wanted, lives at pipeline level (item 4a).
- **D9** There is no `Source.pdf()`. Adapters expose a PDF by setting `Paper.pdf_url`; `Capabilities.pdf` means "this adapter populates `Paper.pdf_url` when an open PDF is known". `download.py` uses `pdf_url`, then Unpaywall.
- **D10** Citation queries (`references`/`citations`) live in their own module, `citation.py` — **not** `citations.py`, because a module named `citations` collides with the re-exported `citations` function (`import researcher_python.citations` then resolves to the function). They return `CitationResult`, deliberately a sibling of `PipelineResult`, not a reuse: it adds `edges`, `truncated`, `subject`, `sources`, `requested`.
- **D11** "Deterministic" means the *local* transformation is a pure function of the per-source responses: a canonical **total** order (`order=` plus a canonical tiebreak of id → folded title → year → folded first author), a fixed `CITATION_SOURCES` precedence (caller order is discarded, so the dedupe merge winner is a function of the source *set*), per-record provenance in `edges`, and caps reported in `truncated`. Live byte-reproducibility over time is explicitly **not** claimed — the graph changes.
- **D12** `strict=True` turns any per-source failure into an exception, so a returned result proves every requested source answered. Adapters still never loop (D8): the retry loop now lives in `_retry.py`, shared by `pipeline` and `citation`, with `pipeline._sleep` / `citation._sleep` kept as the per-caller test seams.
- **D13** Bibliography output is local, not delegated: `format.py` renders BibTeX/RIS/CSL-JSON from `Paper` with no service. Rationale (from the bibify review): bibify is a *formatter* (CSL + citeproc-js backend `bibserver`), not a source; it has been unmaintained since 2020, has no SLA, and its `/api/cite` output is non-deterministic — all three contradict D4/D11. A `Paper`→CSL-JSON bridge is still the right unit to share with a future citeproc or opt-in bibify backend.
- **D14** Web sources (Q&A sites, forums, trackers) are a **separate family** from the scholarly pipeline: new `researcher_python/web_sources/` package with its own `WebResult` / `WebSearchResult` model, `WebSource` base (two hooks: `query_params` + `parse_payload`; base owns transport, throttle, error mapping, paging), and its own `WEB_SOURCES` registry. They are **not** added to `_REGISTRY`/`DEFAULT_SOURCES` (a Stack Overflow answer is not a `Paper`, must not corrupt scholarly export formats), which keeps `test_registry.py`/the README capability-table guard untouched. Reused from the scholarly side: `errors.py` exceptions, `_retry.with_retry`, `squash_text`.
- **D15** `web_search` fans out to one source for now (default `stackoverflow`), retrying `RateLimitError` per `settings.retries` at the wrapper layer (same D8 rule: adapters never loop). A multi-site merge is the scholarly-pipeline shape and can be built on the registry later. Stack Exchange contract, from the shipped docs: `site=` required; wrapper `has_more`/`quota_*`/`backoff` honoured (backoff feeds the throttle before the next request); errors come in the wrapper (`error_name` wins) — `throttle_violation`/429 → `RateLimitError`, all else → `SourceError`.
- **D16** Framework throttling is two-tier: a per-source `WebThrottle` (min interval, like `RateGate`) plus an adaptive cooldown set from the API's `backoff` hint. It deliberately does **not** reuse `RateGate` so all sleeps resolve through `web_sources.base.time` — one test seam covers both tiers (the scholarly tests have to zero `min_interval` because `RateGate` sleeps in its own module). Record/store wrapper meta as `last_response_meta` on the source from `parse_payload`'s return (portable across stubbed tests and real transport).
- **D17** Web records are citable: `web_sources/format.py` renders `WebResult` → BibTeX `@misc` / RIS `GEN` / CSL `webpage`, locally and deterministically like D13. Web-specific conventions: usernames render as CSL `{"literal": ...}` (never a fake family/given split); a site display-name map (`stackoverflow` → "Stack Overflow") feeds `container-title`/`howpublished`/`T2`; CSL id is `<source>-<id>` (a web id is only unique under its source); dates are UTC from epoch `created`; the key stopword set adds Q&A openers (`how`,`why`,`what`,...) so "How to X?" doesn't collapse every key onto `{author}{year}how` (that trap showed up in a test run). `accessed=` is an explicit per-render argument (BibTeX `note`/RIS `N1`/CSL `accessed`) and omitted by default, keeping default bytes deterministic.
- **D18** `reddit` is a web source but its API forces two deviations from the SE shape, both documented in the adapter: (1) **OAuth client credentials are mandatory** — Reddit's anonymous JSON endpoints answer HTTP 403 (verified live; `www.reddit.com/search.json` and `api.reddit.com` both), so `RedditSource` lazy-fetches a bearer token from `/api/v1/access_token` (Basic auth, cached until `expires_in`) and missing/rejected credentials raise `ConfigurationError` naming the env vars, never a raw 401; (2) **rate hints are in HTTP headers**, not the body — the base gained a no-op `_after_response(response)` hook after a 200, `RedditSource` overrides it to read `X-Ratelimit-Remaining/Reset` into the same `note_backoff` path SE's `backoff` uses (the SE adapter is untouched). Paging maps the Listing `after` cursor + `count` onto the base page loop: `query_params` resets `_next_after` on page 1 (a stale cursor from a previous search is a real trap) and carries it + `(page-1)*pagesize` after. `sort` ∈ relevance/hot/top/new/comments, `t` time windows, `subreddit=` scope. Because anonymous capture is blocked, the offline fixture is *constructed from the documented shape*, not live-captured — flagged in the fixture file, README status ("live pending OAuth app") and session log; the parser is defensive enough that a live payload should slot in.
- **D19** The MCP server is a **thin third face**, not a fourth implementation. Rules: (1) every tool is a direct call into the existing pipeline/citation/download/format/web_sources API — no re-implemented logic, no new data model, so MCP behaviour is by construction identical to the CLI/library; (2) `mcp` is an **optional extra**, imported lazily *inside* `build_server()`, so `import researcher_python` stays light and the offline suite runs without it (the repo's "no eager heavy imports" contract holds for the SDK too); (3) the tool logic lives in framework-free `_tool_*` functions so it is unit-testable without the SDK — `@server.tool()` bodies are one-line delegations; (4) settings are loaded once via `load_settings()` (honours `.env`/`RESEARCHER_*`, fixing the documented bare-`Settings()` trap), never a bare default; (5) every `ResearcherError` is returned as data (`{"ok": false, "error": <Class>, "message": …}`) rather than raised, so one throttled source never kills the server and `ConfigurationError` keeps the env-var message; (6) **stdio only** — the standard MCP transport; stdout is the wire, so logging stays on stderr (`setup_logging`'s `StreamHandler` default).
- **D21** **Harvard is a first-class format, not a post-processor.** The module mandates Cite Them Right, so `render_harvard`/`harvard_entry`/`harvard_citation`/`harvard_citation_map` live in `format.py` beside BibTeX/RIS/CSL-JSON, and `bibliography` **defaults to it** (MCP `_BIB_FORMATS[0]` and CLI `--format` default). The reference list is ordered alphabetically by surname — the one thing a BibTeX dump cannot give. Honest gap: Cite Them Right wants edition + place of publication, which `Paper` does not carry, so those segments are **omitted rather than invented**; `accessed=` is an explicit argument, never read from a clock.
- **D22** **Screening state lives on `Paper`**, not in a side store: `label`/`exclusion_reason`/`notes` are reader-owned fields that no source populates, round-trip through `to_json`/`from_json`, and merge "first seen wins, fill the gaps" like every other scalar. That is what makes a screening session resumable and lets the matrices, synthesis and bibliography all reflect the same decisions. `TRIAGE_LABELS` is a closed set: `label_as` rejects an unknown label, `triage_label()` reads one as `unreviewed`.
- **D23** **`SearchFilters`, not five spellings of a year range.** One frozen dataclass (`year_from`/`year_to`/`field`) is the `filters=` argument every `Source.search` takes, so a caller states the search once and every adapter applies it. Each adapter pushes down what its API supports (OpenAlex `from_publication_date`, Crossref `from-pub-date`, PubMed `[dp]`, arXiv `ti:`/`abs:`) and filters the remainder locally, so the contract is uniform where the APIs are not. Semantic Scholar has neither scope nor window, so it filters locally and keeps paging until it has `want` survivors, deduplicating the offset-window overlap. **A record with no year is kept** by a year filter — dropping it would hide exactly the undated grey literature a reader must judge.
- **D24** **`acm` is a Crossref view, not a scraper.** dl.acm.org has no open API; its search results are HTML and scraping them is both fragile and outside the site's terms. Every ACM item carries a `10.1145` DOI that Crossref indexes, so `ACMSource` subclasses `CrossrefSource` and adds `filter=prefix:10.1145` plus a local prefix guard on results. It is **not** in `DEFAULT_SOURCES` (nor is `openaire`): both are facets of Crossref's reach, and an unqualified search would otherwise be inflated by records the broad sources already returned.
- **D25** **`openaire` is the grey-literature route.** The European repository/thesis/deliverable aggregator, free and unauthenticated, with a `resulttype` facet (`other` is where theses and reports land) and `fromDateAccepted`/`toDateAccepted`. It reaches exactly the ProQuest-shaped material the labs cover. Limitation stated in the README: it does **not** cover statutory sources or the law-firm/IAPP policy trackers.
- **D26** **The CLI finally covers the library.** `references`, `citations`, `bibliography`, `matrix`, `synthesis`, `summary`, `label`, `web-search` and `extract` were library-only or script-only; they are now subcommands with `--format`/`--out`, and `search` gained the citation formats plus `--from/--to/--field`. `bibliography --from-file` reads a saved result set, which is the reproducible route — rendering a reference list no longer requires re-running a live search whose results may have changed. Unknown `--columns` is a **usage** error (exit 2), not an `ExportError`.
- **D27** **Matrices are a module, not a citation format.** `matrix.py` renders *tables* (CSV via `csv`, so commas/quotes/newlines in abstracts and notes are quoted), and the Synthesis Matrix is a cross-tab of a dimension against screening, not a partition — a record with two keywords counts in both rows. `screen_summary()` is the PRISMA-shaped count set. Column names are a dict of extractors, so adding one needs no change to the module.
- **D28** **`extract.py` reads the PDFs `download.py` fetches, with `pypdf` an optional extra.** The labs' core skill is extracting information *out of* an article, and the package could download a PDF but not read one. `find_quotes` returns `{"page", "term", "text"}` so a note can cite a page; the matching (`quote_snippets`) is pure and PDF-free, so the rules are unit-testable without the wheel. A single unreadable page degrades to empty text rather than losing the file. Related: `Author.organization` exists because no source can be trusted to know a name is a body — without it, "United Nations" renders as the implausible "Nations, U." in every format.
- **D20** The MCP server is wired into opencode **from this repo**, not from nixos-config: a committed `.opencode/opencode.json` declares the `researcher` server, so the tools are repo-local and clone-portable instead of depending on a global config. Three consequences: (1) it launches via `nix develop --command python -m researcher_python.mcp_server`, so **no `nix build` is required** (the console script only exists in `result/`, which is gitignored, and the dev shell puts the checkout on `PYTHONPATH`); (2) `timeout: 120000` overrides opencode's 5000ms default, which a cold `nix develop` outlives; (3) the flake `shellHook` banner moved to **stderr** — `nix develop --command CMD` inherits the shellHook's stdout, and a stdio MCP server speaking JSON-RPC there is corrupted by any banner. Corollary: *never print to stdout in `shellHook`*. The repo skills (`research-rounds`, `paper-analysis`) are migrated to drive `researcher_*` tools, with the CLI retained as an explicit fallback.

## Known gotchas

- Crossref returned HTTP 429 from dev IP even with `mailto` + 1.2s spacing → don't burn tokens probing live.
- PubMed unscoped `.//` XPath bug was already found once — keep scoped.
- Nix: new deps must appear in `pyproject.toml`, `nix/default.nix`, AND `flake.nix`.
- Bio.Entrez email/tool/api_key are process-global; two PubMedSource instances with different settings in one process clobber each other. Accepted limitation; revisit only if the pipeline ever needs it.
- `nix build` copies only **git-tracked** files into the sandbox (`nix/default.nix` `src = ./..`), so a brand-new module or test must be `git add`ed (staged is enough) before `just build`/`just check` can see it — otherwise `checkPhase` dies at collection with `ModuleNotFoundError` while `nix develop` pytest is green.
- `just` passthrough traps with positional-query recipes: a multi-word query needs nested quotes (`just research '"two words"'`), `--source`/`--refs-source` are `append` flags so each value needs its own flag (no space-separated lists), and a leading `--` is swallowed as the positional, not as the options separator.
- `web_search()`/`search()` default to bare `Settings()` by design (library-safe) — **scripts must pass `settings=rp.load_settings()`** or `.env`/env keys (e.g. `RESEARCHER_STACKEXCHANGE_KEY`) are silently ignored and the caller stays on the anonymous quota. `web_search.py` had this bug; fixed by loading settings in `main()`.
- `export._atomic_text` **creates missing parent directories**, so "write into a non-existent dir" never raises — to force an `ExportError` from a writer in a test, use a path whose parent component is a regular file.
- Reddit's anonymous JSON is **closed**: any keyless `/search.json` (www or api.) answers HTTP 403 with an HTML challenge page. The reddit adapter therefore requires OAuth client credentials — don't try to "fix" it back to anonymous, and don't interpret the 403 as the adapter misbehaving.
